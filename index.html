☁️ Cloud saving · Phase 19

Safe cloud write test. Your existing farm records remain on this device. Only a clearly labeled test record is sent when you click Save test record. Nothing is automatically uploaded, merged, downloaded, or overwritten.

Sign in using your existing invited FlockVault account. Use the same Supabase Project URL and publishable key from Phase 14. Never enter a secret/service_role key.

🧪 Step 2: Save a harmless cloud test record

First run the included Phase16-Cloud-Test-Setup.sql in Supabase SQL Editor. This creates a separate, access-controlled test table. Then sign in above and click Save test record. This will NOT upload your actual FlockVault inventory or change local data.

🐓 Phase 17: Birds & Pens Cloud Upload

Manual upload only. Preview your local birds and pens and check for records already saved to your farm in Supabase. Upload only records that are missing. Nothing is downloaded or merged into your browser. No existing cloud record is updated or deleted.

IMPORTANT: Use the same browser and computer where your real FlockVault records are stored. Keep your exported JSON backup safe. If you see unexpected counts, do not upload.

☁️ Phase 19: Restore Birds and Pens to a New Device

Cloud to this device, manual only. First preview what is in your farm's cloud. Download a JSON copy of the cloud birds and pens for safekeeping. You may then choose to add ONLY missing IDs to this browser. Matching IDs are never replaced, and different contents are flagged as conflicts. Other farm data is not touched.

Before any local import, FlockVault will download a backup of this browser's current farm data (an empty starter backup on a new device). Save that file. Importing requires your confirmation and a page reload.

Phase 19 supports empty-device recovery and a manual, preview-first cloud download of birds and pens. It does not automatically sync or overwrite existing records. Keep JSON backups.

Keep your records safe

Download a JSON backup regularly. Browser data can be lost if the browser is reset or site data is cleared.

Restoring replaces all records currently in this browser. No data is uploaded to a server.
